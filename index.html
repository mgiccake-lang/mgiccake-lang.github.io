01
RESEARCH SYSTEM · Python / Rule Design / Evaluation

研究类型识别：从模糊判断到可验证规则

问题

不同研究设计之间边界容易混淆，单纯依赖关键词会产生大量误判，无法稳定支持后续自动化流程。

我做了什么

拆解研究设计边界，构建关键词规则、优先级策略和判别逻辑；通过 Python 批量测试，对误判样本归因并持续迭代。

结果

相关模块上线后，研究类型判断准确率由约 50% 提升至 80%，并形成可以继续维护和验证的规则体系。

≈50% → 80%
02
DATA WORKFLOW · Mapping / Extraction / Standardization

复杂医学表格自动提取：把非结构化内容变成标准分析表

问题

不同文献表格结构、字段命名和结果口径差异明显，人工整理耗时且难以保持一致。

我做了什么

参与自动提取方案设计，负责字段映射、提取规则和标准化输出格式制定，使跨文献数据能够进入统一分析结构。

结果

方案上线后，复杂表格的数据整理效率提升约 25%，同时降低了后续分析前重复清洗与人工对齐的成本。

+25%
03
AI WORKFLOW · Testing / Error Analysis / Iteration

科研流程 AI Skill 化：从“能跑”到“可重复验证”

问题

科研任务链条长、规则复杂，大模型输出容易在边界任务中出现不稳定和不可复现的问题。

我做了什么

将既有科研流程拆成可重复执行的 Skill，使用真实任务测试，记录错误类型、归因问题、修正规则后再次验证。

结果

累计完成 10+ 医学科研类 Skill 的测试与优化，覆盖文献过滤、研究类型判断、数据提取、偏倚评价、预测因子统计及结局标准化。

10+

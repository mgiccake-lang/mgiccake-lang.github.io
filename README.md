# Ma Yue — Personal Portfolio

A minimal, editorial-style one-page personal portfolio built with plain HTML, CSS and JavaScript.

## Structure

- Intro / About
- Experience with expandable details
- Selected projects & quantified outcomes
- Skills
- Career journey
- Education & awards
- Contact

## Deployment

This repository is intended for GitHub Pages at `mgiccake-lang.github.io`.

No build step or dependencies are required.
